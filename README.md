# Khanya Power Solutions — Demo Website

A self-contained, single-file static site (`index.html`). The "Get a Free Quote" / "Contact us" buttons open the visitor's email client with a pre-populated message to timothy@fy26.fakecustomer.co.za.

## Run locally
Open `index.html` in any browser — that's it.

## Deploy to GitHub Pages
1. Create a new GitHub repo and upload `index.html` and `.nojekyll`.
2. Repo **Settings → Pages → Build and deployment → Deploy from a branch**.
3. Select branch `main`, folder `/ (root)`, Save.
4. Your site goes live at `https://<username>.github.io/<repo>/` within a minute.

The `.nojekyll` file tells GitHub Pages to serve the files as-is.

## Demo note
Fictional brand and data for a Microsoft Copilot demonstration. To test the Contact button on stage, set your default mail app first so the click opens a pre-filled compose window.
